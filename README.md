# Главная карточка клиента — прототип (роль «Офис / лёгкая сеть»)

React-прототип экрана обслуживания дебетовых карт МТС Деньги для сотрудников
офисов и лёгкой сети, реализующий макет из Figma/канваса: идентификация
клиента, каталог продуктов и инцидентов, 6 вкладок продукта, раздел
«Инциденты и обращения».

## Запуск

Сеть в среде, где писался этот код, отключена, поэтому `npm install` и
проверку сборки нужно выполнить у себя:

```bash
npm install
npm run dev
```

Откроется `http://localhost:5173`, роутинг стартует с
`/products/debit-mts-dengi/balance`.

## Структура

```
src/
  api/            — mockData.js (данные-заглушки) + client.js (функции-обёртки
                    над fetchJson; сейчас имитируют сеть, реальный бэкенд
                    подключается заменой ОДНОЙ функции fetchJson)
  hooks/useApi.js — универсальный хук загрузки данных (loading/error/reload)
  components/
    ui/           — примитивы: Button, Pill/StatusPill, Card, Toggle,
                    InfoTooltip, DataTable
    layout/       — RoleBarOffice, IdentityBar, LeftNav, SectionHeader,
                    AppShell (каркас роли)
    shared/       — CardSwitcher, EscalationBar, DocRow — переиспользуются
                    на нескольких вкладках
  pages/          — по одному файлу на вкладку продукта + pages/incidents/
                    для раздела "Инциденты и обращения"
  App.jsx         — роуты (react-router-dom)
```

Каждый крупный блок карточки — самостоятельный модуль (`<Card>` с рамкой и
тенью), а не общий контейнер: шапка роли, идентификация, каталог, шапка
раздела, контент — можно независимо показать/скрыть или заменить, не трогая
соседей.

## Что уже сделано

- Все 6 вкладок продукта «Дебетовые карты МТС Деньги»: Баланс и карты,
  Операции, Блокировки и арест, Кэшбэк, Уведомления, Оформление
- Раздел «Инциденты и обращения» (Массовые / Единичные / Жалобы) с общим
  каталогом слева, доступным из любой вкладки
- Роль «Офис»: «Перевыпустить карту» и «Распечатать» у справок — только
  здесь (см. `BalancePage.jsx`, флаги `canReissue` / `canPrint`)
- Все данные идут через `src/api/client.js` — заглушки с задержкой сети,
  формы объектов см. в `src/api/mockData.js`
